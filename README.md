AI & Technology FAQ Chatbot

Project Description

This project is an AI & Technology FAQ Chatbot developed for the CodeAlpha Artificial Intelligence Internship.

The chatbot answers common questions related to Artificial Intelligence, Machine Learning, Python, ChatGPT, Data Science, NLP, Robotics, and other technology topics.

Features

- Answers AI and technology-related questions
- Simple and beginner-friendly
- Uses Python
- FAQ-based chatbot system
- Easy to expand with more questions and answers

Technologies Used

- Python
- Google Colab
- GitHub

Sample Questions

- What is AI?
- What is Machine Learning?
- What is ChatGPT?
- What is Python?
- What is Generative AI?
